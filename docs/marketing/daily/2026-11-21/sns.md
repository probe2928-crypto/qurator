# SNS 게시 순서·요일 표 — 2026-11-21 (영업큐)

**이번 회차엔 새 SNS 패키지를 만들지 않았다.** 예약 지시는 '내일·모레 작품 기준 1세트씩'이지만 규칙이 우선이고, PRIORITIES 11/21 3번이 "12/8 작품이 아직 없으니 새 SNS 패키지 대신 11/18~20 패키지 3세트의 게시 순서·요일 표를 만든다(예약 안 함, Metricool 12/1까지 금지)"고 정했다. 11/22·11/23 패키지는 이미 11/12·11/13 폴더에 있다. daily.json은 12/7까지다.

- 예약·게시는 하지 않았다. 아래 표는 세준(또는 실무이사)이 직접 올리거나, 12/1 이후 Metricool 예약을 할지 판단할 때 쓰는 순서표다.
- 게시 시각은 넣지 않았다. 우리 계정의 실제 반응 데이터를 확인하지 않았기 때문이다(지어낸 '최적 시간' 금지). 12/1 이후 Metricool `getBestTimeToPostByNetwork`(읽기 전용)로 확인한 뒤 정하자고 제안한다.
- 대조 방법: `data/daily.json`의 날짜별 작품 id 3개를 works.json 제목으로 바꿔 각 패키지 본문에 나오는지 스크립트로 확인했다 → **11/22~12/7 16일 모두 일치(48점/48점)**. 12/1은 11/18 폴더 '부록'(설송도) 문안을 써야 한다.
