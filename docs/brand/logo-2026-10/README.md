# QURATOR 로고 후보 (2026-10-31)

세준 요청으로 "좀 더 고급지게" 만든 세 후보입니다. 세준이 고르기 전까지는 사이트에 적용하지 않습니다.

- A 낙관(Seal): 주홍 인장 안에 디돈 Q, 꼬리가 인장 밖으로 흐름. 파비콘·앱 아이콘에 가장 강함.
- B 아치(Crest): 미술관 아치 안에 Italiana Q와 금빛 점. 메종 문장 느낌. 16px에서는 단순화 버전이 필요.
- C 모듈(Module): 원과 QR 칸으로 만든 꼬리. 현대 미술관풍.

다시 만들기: fontsource의 Bodoni Moda·Cormorant Garamond·Italiana·Jost(OFL)를 내려받고 outline.py의 경로를 맞춘 다음 `python3 build.py`를 실행. 글자는 모두 아웃라인으로 바꿔서 폰트가 없어도 똑같이 보임.
