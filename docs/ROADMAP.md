## 운영 원칙
- 두 상품: Daily Art(개인 구독, 월 30,000원) · QR 도슨트(갤러리 B2B, 전시 30만~100만원, 갤러리 월 9.9만원)
- Daily Art 런칭 혜택: **7일 무료 체험, 이후 월 30,000원**(세준 결정 2026-11-02, '첫 달 9,900원' 대신). 카드 자동결제에만 적용, 1인(이메일) 1회, 8일째 자동 첫 결제, 그 전 해지 시 청구 없음. 계좌이체는 체험 없음. 홍보 문구에 쓸 땐 이 표현 그대로, 앱(Play·iOS) 화면·스토어 문구엔 가격·체험 표기 금지. 카드 결제 오픈(PAY.live) 전에는 사이트에 체험 문구가 자동으로 숨겨져 있음
- 나눔: 수익(구독·갤러리 프로젝트)의 일부를 오리엘 재단(Oriel Foundation · 明窗基金會, 설립 준비 중, 2026-10-27 퍼스트브릭에서 이름 변경)에 기부. 재단 등록 전엔 '할 예정'으로만 표기, 기부 시 data/giving.json에 {date, amount, note{ko,en}, proof} 추가. 비율(GIVE.share) 미정. 구독료는 기부금 아님(세액공제 X)
- 홍보 문구(인스타 캡션·네이버 블로그 원고·특집 소개) 끝에 나눔 한 줄: 'QURATOR 수익의 일부는 오리엘 재단에 기부되어 도움이 필요한 가정과 사랑스런 아이들에게 쓰입니다.' 재단 등록 전에는 기부 금액·수혜 인원 등 숫자를 쓰지 않음, '동남아' 등 특정 지역 표현은 쓰지 않음, 링크는 https://probe2928-crypto.github.io/qurator/#/giving
- 문의·CS: 카카오톡 오픈채팅 https://open.kakao.com/o/gQLZj9Ti
- 디자인: 프랑스 메종 톤 — 종이 #F3EFE6, 잉크 #16140F, 인주 #A8361F, Didone Q 모노그램 + Bodoni Moda 워드마크. 촌스러운 요소·AI 같은 허접함 금지.
- 해설: 미술사 기반, 사실 확인된 내용만. 지어낸 수치·후기 금지. 작품 이미지는 퍼블릭 도메인 또는 자유 라이선스만(CC BY는 imgCredit 표기).
- 운영진 소개: 역사학 전공, 여러 차례(약 5회) 전시 개최·기획 참여. ※ "미술사 전공"·"20회" 표현 금지(사실과 다름, 2026-11-02 세준 정정).

## 다음 작업 (위에서부터)
1. 큐레이션 작품 확충 — 주 3회 회차마다 새 작품 4점 이상(국내 1~2, 해외 2~3), daily.json 다음 회차+1일까지 채우기
2. 아카이브 검색·필터(국내/해외, 작가)
3. 작품·특집별 링크 미리보기 — 해시 라우팅이라 카카오톡·SNS 미리보기는 지금 모두 대표 og.png 한 장. 작품/특집마다 og 태그를 담은 정적 공유 페이지(예: /s/w-pearl.html → #/w/w-pearl로 이동)를 스크립트로 생성하면 작품 이미지가 미리보기에 뜸 (navigator.share 공유·대표 OG 이미지는 2026-10-31 완료)
4. 해외 큐레이션 풀 확충 우선 — 해외 44점(2026-11-04 기준, 11-02엔 40점 — README의 41은 오기였음), 하루 2점씩 쓰면 약 10일마다 반복됨. 30일 미반복하려면 해외 60점 필요
5. 국내 신규 작품 이미지 확인: k-yunduseo, k-pajeok, k-seodang, k-seolsong, k-masang, k-nahyeseok (나혜석 자화상은 위키 문서가 없어 검색어를 일부러 빼 둠 — 작가 사진이 잡히지 않게. 커먼즈 파일 확인되면 commons 고정) (설송도·서당은 단독 위키 문서가 없어 작가/화첩 문서로 검색 — 썸네일이 다른 그림으로 잡히면 img 고정 필요) (이번 회차는 작업 환경에서 위키백과 접속이 막혀 썸네일 검증 못 함 → 다음 회차에 확인 후 img 고정)
6. 시카고 미술관 API 접속 불가 지속 시 검색 출처에서 제외하고 문구 '약 6만 점'으로 조정
7. 갤러리용 소개서 페이지(#/for-galleries): 도입 절차, 캡션 예시, 사례
8. 다국어 확장(일본어·중국어) — 큐레이션 작품부터

5-1. 11/4 새 작품 4점(k-ganghuian-gosa, w-avercamp-skaters, w-friedrich-seaofice, w-klee-parnassum)은 이미지를 직접 못 봐서 tour가 기본 동선(generic). 위키미디어 접속되는 회차에 이미지 보고 data/tour-src/<id>.json 에 좌표 넣고 scripts/tour.py 재실행. 서양 3점은 wiki 문서 이미지, 고사관수도는 커먼즈 파일 고정
