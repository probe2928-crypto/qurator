## 이미지를 볼 수 있는지 다시 시도한 결과
- 셸에서 upload.wikimedia.org: 프록시 403(그대로).
- TinyFish 원격 브라우저(CDP): 접속 주소가 프록시 403 → 우회하지 않음.
- TinyFish 에이전트(1차): 25단계 후 빈 결과(비용 약 $0.4).
- TinyFish 에이전트(2차, 5×5 칸으로 위치 묻기): '죽은 말 C5(가운데 아래)'라고 답함. 하지만 레이크스뮤지엄 설명과 우리 해설은 '왼쪽 아래'다. **에이전트 판독은 원문과 어긋나서 좌표 근거로 쓰지 않는다.**
- 반면 라이브 사이트 확인은 TinyFish fetch_content로 된다. 11/14 밤에 sw.js가 qurator-v61로 배포된 것을 확인했다. 운영QA가 11/5부터 못 하던 라이브 점검을 이것으로 대신할 수 있다.

## 적용 방법(고도화팀)
1. `data/tour-src/<id>.json`의 segs[i]에 x·y·z를 넣는다. 모든 단락에 넣어야 한다. 하나라도 비면 generic으로 돌아간다.
2. `python3 scripts/tour.py data/tour-src --check` → 문제 0 확인 → `python3 scripts/tour.py data/tour-src` 반영.
3. 문장이 안 바뀌므로 음성은 다시 만들 필요 없다.
4. 이미지 도메인이 열리면 위 값을 이미지로 다시 확인한다. 특히 아베르캄프 6단락의 배 위치와 프리드리히의 배 위치를 본다.
